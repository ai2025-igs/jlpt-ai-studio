> **專為台灣高中生與日語自學者打造的超進階 JLPT 日文檢定（N1、N2、N3、N4）全題型證照通關平台**  
> 🌐 **Live Web Site (GitHub Pages)**: [https://ai2025-igs.github.io/jlpt-ai-studio/](https://ai2025-igs.github.io/jlpt-ai-studio/)

| 檢定級別 | 測驗分節與時間配額 | 官方合格總分與單科淘汰門檻 | 內建精編題數與涵蓋大題 | 特色專屬題型支援 |
| :--- | :--- | :--- | :--- | :--- |
| **🏆 JLPT N2** (預設主力) | 二節制：`105m` 筆試 + `50m` 聽解 | 總分 `≥90/180`；三科皆須 `≥19/60` | **60 題**（19 個官方細分大題全滿） | **問題3 語形成**、**A/B 兩文統合比較讀解**、**問題5 長篇統合理解聽解** |
| **🌉 JLPT N3** (中級橋樑) | 三節制：`30m` 字彙 + `70m` 文法讀解 + `40m` 聽解 | 總分 `≥95/180`；三科皆須 `≥19/60` | **24 題**（17 個官方細分大題） | **問題4 看圖情境発話表現 (內建 SVG 角色箭頭卡)**、分級 `<ruby>` 振假名 |

## 🧠 2. 內建 8 大教育心理學與認知科學引擎

| 代碼 | 教學理論與心理計量模型 | 系統內對應之具體互動功能 |
| :--- | :--- | :--- |
| **P1** | **Bloom's Revised Taxonomy** (布魯姆六階認知鷹架) | 每道題目標註 `L1 記憶` ➔ `L2 理解` ➔ `L3 應用` ➔ `L4 分析 (★星號重組)` ➔ `L5 評鑑 (A/B 統合)` ➔ `L6 創造 (AI 延伸造句)`。 |
| **P2** | **Zimmerman 3-Phase SRL** (自我調節學習與信心度校準) | 作答前設定 `25%~100%` 把握度滑桿，即時計算「主觀信心 - 實際正確率」校準差，精準攔截最危險的**🚨 高信心盲點 (High-Confidence Blindspot)**。 |
| **P3** | **Sweller Cognitive Load & Fading Scaffolding** (認知負荷與漸進鷹架) | 頂部提供 **「🌱 教學鷹架模式」**（開啟分級振假名、💡 蘇格拉底不洩題提示、✂️ 排除 1 個誘答項）與 **「⚔️ 考場實戰模式」** 一鍵切換。 |
| **P4** | **Odlin Contrastive Analysis & L1 Transfer** (台日漢字正負遷移理論) | 專為台灣高中生設計 **「🇹🇼⇄🇯🇵 漢字母語正負遷移透鏡」**，拆解國語清濁音干擾、同形異義假朋友（如 `我慢`、`手紙`、`都合`）與助詞格關係盲點。 |
| **P5** | **Paivio Dual-Coding Theory** (視覺與聽覺雙碼理論) | N3/N4 聽解「発話表現」配備 **SVG 情境角色箭頭卡**；情報検索配備結構化傳單表格；聽解配備 24 段動態頻譜與男女雙聲道色標。 |
| **P6** | **Worked Example & Syntactic Chunking** (工作範例與語塊接續鏈) | 針對「`＿＿ ＿＿ ★ ＿＿`」星號排句題，提供 **4 格互動語塊沙盒** 與 **「🔗 語法接續鏈圖解」**，訓練從句尾逆向推導助詞接續。 |
| **P7** | **Bjork Desirable Difficulties & Interleaving** (必要難度與交錯檢索) | 預設提供「⚡ 跨題型交錯實戰」與 **「🙈 考場盲聽防呆遮罩 (Poka-Yoke)」**，防止視覺文字搶奪聽覺工作記憶。 |
| **P8** | **Lord 2PL-IRT + Jarrett Ye FSRS v5** (項目反應理論與自由間隔重複) | 即時推估 `/180` 量尺分數與 **19 分單科淘汰紅線警報**，並依據記憶穩定度 $S$ 與難度 $D$ 排定 `T+1d / T+3d / T+14d` 複習佇列。 |

## 🗺️ 3. 台灣高中生五階證照通關標準工作流 (5-Stage Pass Workflow)

1. **Stage 1（落點快篩）**：在預設 `N2`（或目標級別）的「⚡ 跨題型交錯實戰」作答 6~10 題，取得初始 2PL-IRT 能力值 $\hat{\theta}$ 與六維度雷達落點。
2. **Stage 2（鷹架解構）**：開啟 **「🌱 教學鷹架模式」**，善用「💡 蘇格拉底提示」與答題後的「🇹🇼⇄🇯🇵 台灣高中生漢字母語正負遷移透鏡」消除母語干擾。
3. **Stage 3（雙碼盲聽）**：進入「🎧 聽解全題型」，透過 `edge-tts` 男女雙聲道音訊（支援 `0.85x / 1.0x / 1.15x` 變速與單句重播）特訓轉折信號詞（`実は`、`それより`、`ただ`）。
4. **Stage 4（盲點攔截）**：點擊頂部「🔄 錯題與脆弱重練」，優先清零 `FSRS T+1d` 佇列中的「🚨 高信心盲點」，確保三科預估分數皆遠離 `19/60` 單科否決紅線。
5. **Stage 5（考場實戰與 NotebookLM 複習）**：切換至 **「⚔️ 考場實戰模式」** 驗收配速，並點擊「📓 匯出 NotebookLM」將個人錯題與聽解逐字稿轉為 AI Podcast 隨身聽。

## 🛠️ 4. 專案目錄結構與本地驗證指令

```text
jlpt-ai-studio/
├── index.html                        # 模組化主入口網站 (GitHub Pages Live)
├── assets/
│   ├── css/custom.css                # 暗色認知降熵樣式與分級 <ruby> 規則
│   └── js/
│       ├── psychometric.js           # N1-N4 考綱規格、2PL-IRT 量尺推估、FSRS v5 排程與 8 大教學法
│       ├── audio-engine.js           # 880/698Hz 考場鐘聲 + edge-tts 雙聲道 MP3 + WebSpeech 備援
│       └── app.js                    # 四級別路由、教學鷹架、星號重組沙盒、localStorage 備份與 BYOK 金鑰保險箱
├── data/
│   ├── n2_bank.json                  # N2 完整 60 題庫 (涵蓋全部 19 個官方細分大題)
│   ├── n3_bank.json                  # N3 完整 24 題庫 (含看圖發話 SVG 與分級振假名)
│   ├── n4_bank.json                  # N4 完整 24 題庫 (含看圖發話 SVG 與基礎核心文法)
│   └── n1_bank.json                  # N1 完整 24 題庫 (含社論 A/B 比較與三人統合聽解)
├── audio/
│   └── {n1,n2,n3,n4}/*.mp3           # 29 首預渲染 edge-tts 真人級雙聲道聽解 MP3
├── dist/
│   └── jlpt_n1_n4_standalone_v3.html # 100% 離線單檔旗艦版 (同步更新至 R:\jlpt_n2_ai.html)
└── scripts/
    ├── validate_jlpt_studio.py       # 確定性 AQE 題庫、音檔與振假名審計閘門
    └── build_standalone.py           # DOM ID 一致性檢查與單檔封裝編譯器
```

### 執行自動化品質驗證與單檔編譯：

```bash
python scripts/validate_jlpt_studio.py --level ALL --strict-aqe --check-audio --check-furigana
python scripts/build_standalone.py
```
