## 🖥️ 2. 1080P (`1920×1080`) 三分頁 (3-Tab) 認知分流與官方樣題 UI 對齊

針對 `1920×1080` 標準桌機解析度，系統將工作區拆分為 **3 個頂層認知分頁 (Tabs)**，確保作答時零垂直捲動干擾：

1. **🎯 Tab 1：互動式 AI 刷題與認知診斷系統 (官方樣題 UI)**
   - **左欄 (7 Cols) 官方樣題測驗框**：100% 對齊 `jlpt.jp/tw/samples/` 官方樣題介面 — 頂部左側級別色塊、中段雙層大題號碼選擇器（筆試 `1..14` ＋ 聽解 `🔊15..19`）、右側藍色 `[?]` 指引鈕、聽解 **4 步 `答え方` 綠框互動跳段精聽器 (`STEP ① ➔ STEP ④`)**、情境 SVG **`🔍 クリックで拡大` 點圖放大視窗**、`2×2` 膠囊選項 (`1..4`) 與底部 `[◀ まえへ]` / `[✔ 解答・AI診断]` / `[つぎへ ▶]` 導覽列（支援全鍵盤熱鍵 `1~4 / Enter / ←→ / R / H / F`）。
   - **右欄 (5 Cols) 即時教學鷹架與診斷塢**：未作答前顯示「SRL 四象限說明、台灣高中生漢字遷移快篩提示、2PL-IRT 即時落點迷你條」；提交答案後零捲動原地切換為「`🇹🇼⇄🇯🇵 台日漢字正負遷移透鏡`、`🔗 語法接續鏈圖解` 與 `✅/❌ 四選項誘答深度拆解`」。
2. **📊 Tab 2：量尺分數推估與過關機率 & AI 弱點處方箋**
   - 2PL-IRT 量尺分數推估（`/180` 總分、言語知識、讀解、聽解）、單科 `19/60`（N4/N5 合併 `38/120`）淘汰紅線警報、**`🖨️ 列印官方格式合否結果通知書`**、6D 六角認知雷達圖與 AI 弱點處方箋。
3. **📋 Tab 3：記憶排程與題庫導覽佇列 & 考綱百寶箱 (Others)**
   - FSRS v5 間隔重複排程佇列（含 **`🔍 即時全文關鍵字檢索框`**）、**`⬇️ NotebookLM 雙人 Podcast .md 學習包直出下載`**、Google Sheets 雲端同步與學習增效百寶箱（動詞活用表、自動詞/他動詞配對、授受表現方向箭頭、23 張台日假朋友 & 東京高低音調 `[0][1][2]` 發音閃卡）。
